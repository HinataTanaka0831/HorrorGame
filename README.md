# [ゲームのタイトル]
・呪われた校舎

## 🎮 概要
・ステージ内を巡回している敵につかまらないように、
アイテムの「おふだ」を4枚、脱出口に集めて脱出を目指す
ホラーゲームです。

## 🕹️ 遊び方（PCのみ）
- WASDキーで移動
- Rキーでアイテム取得
- Fキーでアイテムの使用
- Eキーでしゃがみ
- LShiftキー+WASDキーでダッシュ
- マウス移動で視点操作
- 左クリックでライトのON/OFF切り替え
- Escキーでゲーム終了

## ✨ アピールポイント・頑張ったところ
- 敵がステージ内を巡回する処理の作成に苦労しました。
- タイトル画面の砂嵐やジャンプスケア等を実装し、怖いと感じられるような雰囲気にできるようこだわりました。
